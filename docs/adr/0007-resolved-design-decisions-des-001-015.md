# ADR-0007: Baseline Resolution of Design Decisions DES-001..015 and Local/CI Target Environment

**Status:** Accepted (Gate 9 Approved 2026-11-01) | **Date:** 2026-11-01 | **Owner:** AW Shortlink product maintainers (project owner)

## Context
Detailed system design (`design/system-design.md` §15) identified fifteen open technical and policy design questions (`DES-001` through `DES-015`) that needed to be locked across the data model (`SPEC-05`), access control matrix (`SPEC-06`), resolver algorithms (`SPEC-07`), and API contracts (`SPEC-08`) before the Gate 9 cross-specification review (`SPEC-09`). Additionally, because production hosting discovery (`HOST-01..17`, `SPEC-01`) awaits operator verification, development and CI require a pinned production-equivalent baseline environment.

## Decision

### 1. Resolved Design Decisions (`DES-001`..`DES-015`)
| ID | Decision Topic | Locked Specification Baseline | Affected Specs / Issues |
| --- | --- | --- | --- |
| **DES-001** | Primary key strategy | **UUIDv7** (application-generated, time-ordered, non-enumerable) for all domain and IAM tables; **`BIGINT GENERATED ALWAYS AS IDENTITY`** for append-only audit tables (`link_audit_events`, `access_decision_audit`) to enforce strict monotonic hash-chain ordering. | `data-model.md`, `system-design.md` §7.1, #5, #12, #18 |
| **DES-002** | Organizational unit hierarchy model | **Closure table (`shortlink.unit_closure`)** storing `(ancestor_id, descendant_id, depth)`. Requires no optional PostgreSQL extensions (`ltree` not assumed on shared host) and keeps RLS policies non-recursive via server-expanded `app.unit_ids`. | `data-model.md`, `postgresql-rls-design.md`, #5, #6, #38, #39 |
| **DES-003** | Public HTTP status for suspended links | **HTTP `404 Not Found`** (identical safe generic page as unknown slug so attackers receive no oracle or confirmation signal). Intentionally archived or expired links with public tombstone return **HTTP `410 Gone`**. | `redirect-algorithm.md`, `openapi.yaml`, #7, #14, #20 |
| **DES-004** | Editor analytics visibility | **Own links within assigned unit** (`analytics.view` scoped by RBAC/ABAC so editors can inspect aggregate clicks on links they authored or maintain in their unit; unit-wide and cross-unit analytics require `unit_admin`, `analyst`, or `org_admin`). | `access-control.md`, `identity-rbac-abac.md`, #6, #17, #19 |
| **DES-005** | Small-cohort privacy suppression threshold | **$k = 10$**. Any cell `(link × date_utc × channel_code)` with count `1..9` is masked as `"<10"` in UI and standard exports; `0` is displayed as `0`. Unsuppressed totals require `analytics.export` under DPO-approved reporting policy. | `threat-model-privacy.md`, `system-design.md` §12, #3, #17, #33 |
| **DES-006** | Multi-factor authentication (MFA) baseline | **TOTP (RFC 6238) mandatory** for all authenticated staff accounts; **WebAuthn/passkeys optional** progressive enhancement. Privileged actions (`links.suspend`, `users.disable`, `user_roles.assign`, `roles.permissions.update`, `policies.publish`) require verified MFA in session (`POL-PRIV-MFA`). | `identity-rbac-abac.md`, `system-design.md` §11.2, #6, #11, #19 |
| **DES-007** | Raw per-click event storage | **Disabled (`off`) by default** per ADR-0003. Only bounded daily aggregates (`link_daily_stats`) are persisted at runtime; `link_click_events` is omitted from active P0 runtime writes unless explicitly enabled post-DPIA. | `data-model.md`, `threat-model-privacy.md`, #3, #5, #17 |
| **DES-008** | Cleartext `http://` destination exception | **Never allowed by default** (`url_canonical ~ '^https://'`). An institutional `http://` exception requires an explicit time-bounded DPO + Security Owner waiver recorded in `destination_domain_rules`. | `redirect-algorithm.md`, `system-design.md` §11.1, #3, #7, #13 |
| **DES-009** | P0 link publication approval model (before P1 #27) | **Role-based publish (`links.approve`) + mandatory Separation-of-Duties ABAC policy (`POL-LINK-SOD`)** forbidding self-approval (`actor.id == resource.creator_id`) whenever destination risk is `medium` or `high`. Full review queue UI/workflow ships in P1 (#27). | `access-control.md`, `system-design.md` §5.3/§8.3, #6, #15, #19, #27 |
| **DES-010** | PostgreSQL backup identity vs. RLS (`THR-021`) | Dedicated operator-only backup role **`awshortlink_backup` with `BYPASSRLS`** (restricted to backup automation/operator execution window over direct TLS connection) or verified provider snapshot, accompanied by mandatory row-count and `pg_policies` restore verification. | `postgresql-rls-design.md`, `deployment-no-ssh.md`, #1, #38, #43 |
| **DES-011** | Click counter write path | **Direct atomic `INSERT ... ON CONFLICT DO UPDATE`** on `shortlink.link_daily_stats` via narrow `SECURITY DEFINER` function `shortlink.record_click(uuid, smallint)` executed after HTTP response flush. Buffer table (`link_click_buffer`) reserved only if load testing shows row contention. | `redirect-algorithm.md`, `system-design.md` §5.1, #7, #14, #17 |
| **DES-012** | Admin session lifetime | **30 minutes idle timeout / 8 hours absolute maximum session lifetime**, cookie scoped to `/buka` with `Secure; HttpOnly; SameSite=Lax`, rotated on login and privilege change. | `identity-rbac-abac.md`, `system-design.md` §11.2, #6, #11 |
| **DES-013** | Slug character set and length | **Lowercase ASCII `[a-z0-9-]`**, length **3..64**, no leading/trailing hyphen, no consecutive `--` (`^[a-z0-9](?:[a-z0-9-]{1,62}[a-z0-9])$`). Uppercase ASCII inputs are canonicalized to lowercase before lookup; non-ASCII/Unicode slugs are rejected in MVP. | `redirect-algorithm.md`, `data-model.md`, #5, #7, #12, #14 |
| **DES-014** | Destination domain allowlist governance | **Organisation IT / Security Owner** administers `destination_domain_rules` (`settings.domain_rules.manage`) in consultation with the communications office. | `threat-model-privacy.md`, `access-control.md`, #3, #13 |
| **DES-015** | REST API exposure in P0 | **Internal service contract in P0** (backing Filament Actions and contract/integration tests under `/buka/api/v1`); external third-party bearer token provisioning UI/workflow is P1 (#30). | `openapi.yaml`, `system-design.md` §10, #8, #15, #30 |

### 2. Local / CI Target Environment vs. Production Host Audit (`SPEC-01`)
- **Development, Contract, Integration, and Security CI (`#10`–`#23`, `#38`–`#42`)** target **PostgreSQL 17/18** (with `ENABLE/FORCE ROW LEVEL SECURITY` and separate `awshortlink_migrator`, `awshortlink_app`, `awshortlink_resolver`, and `awshortlink_backup` roles) and **PHP >= 8.3** under **Topology A** (dedicated `/buka/` front controller with private app root outside webroot) or **Topology C** (reverse-proxied dedicated host).
- **Production deployment (`#24`–`#26`, `#43`, Gate 15)** remains strictly blocked on verified `HOST-01..17` operator evidence on the target infrastructure.

## Consequences
- Removes ambiguity across `SPEC-05`, `SPEC-06`, `SPEC-07`, and `SPEC-08` so cross-specification consistency (`SPEC-09` / Gate 9) can be verified deterministically.
- Preserves fail-closed governance: locking technical design defaults does not bypass human Gate 9 approval, actual usability validation (`UXT-001..014`), or production host verification (`HOST-01..17`).
